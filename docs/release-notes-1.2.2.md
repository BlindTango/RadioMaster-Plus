# RadioMaster+ 1.2.2

This release repairs the Quill Radio features and the podcast Refresh Episodes context menu.

- Internet Archive now opens collections, items, and their actual audio files, including AAC. Search results open the item's track list instead of guessing a stream filename.
- Failed sources can be retried. Late source results preserve the selected search row and do not replace another section's list.
- Refresh Episodes closes its menu and returns focus to the episode list before refreshing.
- Podcast folders open with Enter and provide Back to Subscriptions. Unheard badges update when an episode finishes.
- Continue Listening saves progress for podcasts, audiobook chapters, and local media, ordered by recent listening. Podcasts can resume online without a download.
- Song History's Search Lyrics action now opens the requested lyrics lookup.
- Listening statistics include the active session and identify the playing source independently of the visible tab.
- Catalog Status computes quarterly, six-month, and yearly updates using the actual calendar schedule.
- Live time-shift resolves station playlist URLs and reports the buffer's playback position accurately. First-run Skip also supports Escape.
- Updated the User Manual, Quick Start Guide, release history, and feature sign-off checklist.

The first live Jump Back still needs about 15 to 20 seconds to collect audio. It cannot recover audio from before that press. Internet Archive usage terms vary by item; consult its item page.
