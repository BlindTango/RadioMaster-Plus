# RadioMaster+ 1.2.3

The seek slider now works for media files and live time-shift playback.

- Fixed audio duration reporting so the position slider enables for media files.
- Added a visible Seek label and keyboard controls: Left/Right move one second, Page Up/Page Down move ten seconds, and Home/End move to the start/end.
- Mouse dragging seeks when released; playback updates preserve the thumb while dragging.
- During live time-shift playback, Time-shift Position covers the growing recorded buffer, including newly recorded audio. End returns to live playback.
- The time-shift display shows how far behind live you are. Unbuffered live streams keep seek controls disabled.
- Updated the User Manual, Quick Start Guide, and in-app release history.

Start Jump Back to collect a live buffer before using the time-shift slider. The first jump still needs about 15 to 20 seconds of incoming audio.
